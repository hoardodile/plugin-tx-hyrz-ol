# 角色帧动画 · 精灵帧动画演示

在 hoardodile 里播放**已导出的 2D 角色目录**：按帧播放、动作切换、按帧触发的角色音频。

角色是 2D 精灵帧动画（五层精灵换帧曲线 + 位移/缩放/旋转，30 fps，约 150 张精灵、
约 75 个动作）。导出格式见 `docs/format.md`；导出工具是另一个私有项目，不在本仓库内。

## 功能

- 识别两类资源：**单个自包含角色目录**（根目录含 `character.json`，可单独保留/
  删除）与**合集根目录**（含 `catalog.json`，带角色选择器）。
- 演示区：动作列表（按 待机/移动/普攻/技能/受击/状态 分组）、canvas 帧动画
  （播放/暂停、逐帧、重播、速度、缩放、循环、参考线、时间轴）、当前帧与绘制层数。
- 角色音频：按帧列出导出数据里的音效事件（音量一并还原，非 1.0 显示 `x0.80` 角标），
  可播放已解析样本，并显示事件→样本的解析状态（未解析会明确标注）。
- 卡片：`cover.png` 作为封面；卡片四角显示中英文案（通过 manifest i18n key）。
- 权限：`sourceMeta`（其余保持默认关闭）。

## 要求

- hoardodile ≥ 0.2.0。
- 一个已导出的角色目录或合集目录；插件本身不附带任何数据。
- 安装前请确认信任该仓库——插件代码在受限沙箱中作为服务端代码运行。
