# キャラクター・フレームアニメーション — スプライトアニメーションビューア

**書き出し済みの 2D キャラクターフォルダ**を hoardodile 上で再生します：
フレーム単位の再生、アクション切り替え、フレームに紐づくキャラクター音声。

キャラクターは 2D スプライトアニメーションです（5 レイヤーの差し替えカーブ +
位置/拡大縮小/回転、30 fps、1 キャラあたり約 150 スプライト・約 75 アクション）。
書き出し形式は `docs/format.md` を参照。書き出しツール自体は別の非公開プロジェクトで、
このリポジトリには含まれません。

## 機能

- 2 種類のリソースを認識：`character.json` を含む**自己完結したキャラクター
  フォルダ**（個別に保持・削除できる）と、`catalog.json` を含む**コレクション
  ルート**（キャラクター選択付き）。
- ビューア：アクション一覧（待機/移動/通常攻撃/スキル/被弾/状態でグループ化）、
  canvas のフレームプレイヤー（再生・一時停止、コマ送り、リスタート、速度、
  ズーム、ループ、ガイド、タイムライン）、現在フレームと描画レイヤー数。
- キャラクター音声：書き出しデータがフレームごとに発火する音声イベントを一覧表示し、
  書き出された音量も復元（1.0 以外は `x0.80` バッジ）。サンプルに解決できたものは
  再生可能で、未解決も明示。
- カード：`cover.png` をカバーに、四隅の文言は manifest の i18n キー経由。

## 要件

- hoardodile ≥ 0.2.0。
- 書き出し済みのキャラクターフォルダまたはコレクション。プラグインにデータは
  同梱されません。
- インストール前にリポジトリを信頼してください——プラグインコードは制限付き
  サンドボックス内のサーバー側コードとして実行されます。
